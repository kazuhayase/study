## 2026-04-12 アーキテクチャ: Centralized Analytics Layer

**決定**: 各エンティティのデータを単一Snowflakeアカウントに集約するBronze/Silver/Gold構造を採用

**理由**: 各エンティティが自社システムを保持しつつ、CIOが横断クエリを実行できる最小構成

**却下した選択肢**:
- Option A: 各エンティティで個別DB → クロスエンティティ集計が困難
- Option B: 完全統合DB → 各エンティティの自律性が失われる、移行コスト大

**影響範囲**: 全スキーマ設計

## 2026-04-12 AI利用方針: パース・正規化のみ

**決定**: AIはExcelデータのパース・正規化にのみ使用。1-5スコアの推定・変更は禁止。

**理由**: AIによるスコア推定がHRMOSパイロット失敗の原因（過剰評価）。人間の評価を尊重。

**却下した選択肢**: AIによるスキルレベル推定 → 信頼性問題・前例の失敗から却下

**影響範囲**: Bronze→Silver パイプライン設計、AIプロンプト設計

## 2026-04-18 PII暗号化: 列レベルENCRYPT採用

**決定**: PoCフェーズは専用ロール未発行のため、列レベル暗号化（AES-256-GCM）で対応

**理由**: Snowflakeのロール設計を誤解しており、タレマネ担当以外もアクセス可能な状態だったため緊急対応

**却下した選択肢**: スキーマ分離による即時RBAC → 専用DB/スキーマの申請が必要で時間がかかる

**影響範囲**: entity_employees.name_enc, employee_reviews.score_enc / comment_enc
**本番移行時**: Dynamic Data Masking + 専用ロールに切り替え予定
