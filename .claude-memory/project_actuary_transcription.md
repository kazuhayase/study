## スクリプト技術メモ

- **PDFライブラリ**: pdfplumber（poppler必要）
- **Excelライブラリ**: openpyxl
- **問題解析**: 3段階パース（問題N → (N) → ①②③）
- **所感検出**: SOKEN_PAT with `text.replace('\n','')` で行折り返しに対応
- **章分類**: 設問テキストのみで判断（解答テキストは含めない）
- **2005/2004の注意**: OCR誤読で `問題` → `間題` あり。MONDAI_PAT で両対応済み
