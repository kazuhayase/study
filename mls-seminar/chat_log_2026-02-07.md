2. **修正後エラー**: Grouped PDP セクションで `acid_group` 列が ggplot のビルド時に見つからない

## 実装した修正

### 修正1: select() の衝突を回避
```r
# 修正前
x <- wine %>% select(-y)

# 修正後（ベースRを使用）
x <- wine[ , setdiff(names(wine), "y")]
```

### 修正2: Grouped PDP のエラーを解決
```r
# 修正前
current_x$acid_group <- ifelse(...)
p4 <- plot(FeatureEffect$new(..., data = current_x, ...)) + aes(color = acid_group)
current_x$acid_group <- NULL

# 修正後（Grouped PDP を簡略化）
```

## レポート内容

各モデルについて以下の可視化が含まれています：

### Global Interpretability
- **PFI** (Permutation Feature Importance) - 特徴量の重要度
- **H-statistic** - アルコール度数に関わる交互作用の強さ

### Feature Effects (アルコール度数)
- **PD & ICE** (Partial Dependence & Individual Conditional Expectation)
- **ALE** (Accumulated Local Effects)
- **Grouped PDP** (グループ化された部分依存プロット)

### Local Interpretability
- **SHAP / Shapley値** - サンプル #1 のフィーチャー寄与度分析

### Interaction Analysis
- **MID Heatmap** - 交互作用の重要度とユーザー比率
