# プロンプト（共通ベース）

```
以下のメールを添削してください。

【添削の方針】
- 宛先：{{相手の立場（例：社外取引先、上司、部下）}}
- トーン：{{例：丁寧・簡潔・フレンドリー}}
- 重点：{{例：誤字脱字、敬語、論理構成、簡潔さ}}

【元のメール】
---
{{email}}
---

出力形式：
1. 添削後のメール全文
2. 変更箇所と理由（箇条書き）
```

# モデル別バリエーション

## Claude向け

複数パターンを出させる場合：

```
添削後のメールを「丁寧版」と「簡潔版」の2パターン出力してください。
```

件名も含めて見直したい場合：

```
件名の改善案も3案提示してください。
```

## Gemini向け

Gmail Draft と連携する場合はそのままコピペで使える形式を指定：

```
プレーンテキスト形式で出力してください（Markdownなし）。
```

# 使用メモ

- 社外向け：敬語チェックを重点に
- 英語メール：日英切り替えは「英語で添削してください」を冒頭に追加
- クレーム対応：トーンに「誠実・謝罪トーン」を指定
