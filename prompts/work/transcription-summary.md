# プロンプト（共通ベース）

```
以下は会議/インタビューの文字起こしです。次の形式で要約してください。

【目的・背景】（1〜2文）

【決定事項】
- 

【議論のポイント】（3〜5点）
- 

【TODO・宿題】（担当者と期限があれば記載）
- 

【次回に持ち越した論点】
- 

文字起こし：
---
{{transcript}}
---
```

# モデル別バリエーション

## Claude向け

長い文字起こしはそのまま貼り付けてOK。追加指示の例：

```
※ 発言者名は「Aさん」「Bさん」のように匿名化してください。
※ 技術用語はそのまま残してください。
※ 重複・言い淀みは除いて読みやすくしてください。
```

## Gemini向け

Google Docs/Meetの文字起こしと相性が良い。Drive連携で直接読み込み可能。

```
（上記共通プロンプトをそのまま使用）
※ 箇条書きではなくMarkdown表形式でTODOを出力してください。
```

# 使用メモ

- 社内会議：匿名化オプションをつける
- 1on1：「決定事項」「TODO」のみ抽出する短縮版でも十分
- 英語文字起こし：「日本語で要約してください」を末尾に追加
