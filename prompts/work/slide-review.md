# プロンプト（共通ベース）

```
以下の資料をレビューしてください。

【資料の目的・対象読者】
{{例：経営層向け四半期報告、社外向け提案書}}

【レビュー観点】（不要な項目は削除）
- [ ] 論理構成（ストーリーライン）
- [ ] メッセージの明確さ（1スライド1メッセージ）
- [ ] データ・根拠の妥当性
- [ ] 言葉の統一・表記ゆれ
- [ ] 聴衆に伝わりやすいか

【資料内容】
---
{{ここにテキストを貼り付け、またはファイルをアップロード}}
---

出力形式：
1. 総評（3文以内）
2. スライドごとのコメント（番号付き）
3. 優先度高の修正点（TOP3）
```

# モデル別バリエーション

## Claude向け

テキストをコピペして貼り付ける運用。スライド番号を手動で付けると精度が上がる：

```
各スライドの内容を「[スライド1] タイトル：...」の形式で貼り付けてください。
```

## Gemini向け

PDFやPPTXをそのままアップロードして使用可能。

```
（ファイルをアップロードし、上記共通プロンプトをそのまま使用）
```

# 使用メモ

- 提案書：「論理構成」「メッセージの明確さ」を重点に
- 社内報告：「データの妥当性」「言葉の統一」を重点に
- 英語資料：「英語で」を冒頭に追加、または日本語でコメントを返させる
