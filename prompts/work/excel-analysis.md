# 使用メモ

- 個人情報を含むExcelはアップロード禁止。CSVに変換後、氏名列を削除してから使う
- ピボット集計結果だけ貼る方が精度が高い場合が多い
- 「グラフにするならどの形式が適切か」も聞くと有用
